# 生命周期与设计

## 动作状态机

`ActionModPlayer` 的状态由以下字段组成：

- `CurrentAnimAction`：当前动作实例，空值表示没有动作。
- `CurrentActionElapsedFrame`：已经推进的帧数，从 0 开始。
- `CurrentActionFrame`：用于取节点的动作帧，等于 `min(elapsed, TotalFrame - 1)`。
- `CurrentActionProgress`：整体进度，约为 `elapsed / TotalFrame`。

开始动作时，`StartActionLocal` 会检查动作和总帧数，按需中断旧动作，重置已播放帧，将 `rotation` 写入 `StartRotation`，应用物品时间，并调用 `OnStart`。随后每个更新周期执行 `UpdateCurrentAction`：

1. 如果已播放帧数大于等于总帧数，调用 `OnFinish` 并清空状态。
2. 否则以当前动作帧调用 `AnimAction.Update`。
3. `CurrentActionElapsedFrame` 加一。

因此动作帧 0 会实际执行一次；总帧数为 `N` 的动作在 elapsed 为 `0..N-1` 时更新，在下一次更新时结束。动作结束后 `CurrentAnimAction` 和 elapsed 都会归零。

`FrameEffects` 走 `AnimAction.ApplyFrameEffects`，只处理当前帧激活的节点；它适合设置玩家的临时表现状态。逻辑节点则在 `PostUpdate` 中通过 `Update` 执行。

## 节点模型

`AnimAction` 的节点列表是有序的，但没有互斥或冲突检测。多个节点只要区间重叠，就会在同一帧按添加顺序依次运行，后运行的节点可能覆盖前一个节点对玩家状态的设置。

节点基类提供三个扩展点：

- `Update`：逻辑更新，例如设置手臂姿态、改变腿部帧、生成一次性事件。
- `ApplyFrameEffects`：帧表现更新，例如设置免疫、发光或其他每帧玩家效果。
- `Draw`：在指定玩家绘制层绘制额外内容。

`AnimAction` 还提供两个监听器：

- `FrameUpdateListener`：每帧所有节点之前调用一次。
- `PreNodeUpdateListener`：每个激活节点之前调用；返回 `false` 可跳过该节点本帧执行。

## 内置节点

### `ArmActionNode`

在 `Front` 或 `Back` 复合手臂上对伸展量和旋转角进行线性过渡。伸展量使用 `None/Quarter/ThreeQuarters/Full` 四档，内部先转成浮点值插值再量化回 Terraria 枚举；旋转角最后乘以当前 `player.direction`。

### `LegFrameActionNode`

在两个腿部帧索引之间插值，四舍五入后写入 `player.legFrame`，并将 `legFrameCounter` 置零。开始和结束索引都不能小于 0。

### `CallbackActionNode`

由单帧区间 `[triggerFrame, triggerFrame + 1)` 组成。它只在 `Main.LocalPlayer` 上调用回调，适合本地音效、粒子或客户端表现，不适合作为服务器权威的伤害逻辑。

### `ShootActionNode`

也是单帧节点，调用 `AnimAction.ShootFromAction`。辅助函数会检查玩家有效、存活、归属本机、手持物品有效、`CanShoot` 和弹幕类型，然后执行改变方向、`ModifyShootStats`、`Shoot` 钩子，最后通过 `GamePlayStatic.NewProjectile` 生成弹幕。若节点提供 `configureProjectile`，它会在弹幕初始化和 `OnSpawn` 完成后、首个同步包发送前执行，适合写入需要随首包同步的自定义参数。弹幕本体再由 Terraria 的弹幕同步机制负责传播。

## 绘制层

四个 `PlayerDrawLayer` 通过 `ActionPlayerDrawLayer` 统一转发到当前动作的 `Draw`：

| 枚举 | Terraria 相对位置 |
| --- | --- |
| `UnderPlayer` | 整个玩家下方 |
| `UnderArm` | 前手臂下方 |
| `OverArm` | 手臂和武器上方 |
| `OverPlayer` | 整个玩家上方 |

绘制层仅在 `HasAction` 时可见；节点自身仍需用 `IsActive(actionFrame)` 判断区间（基类 `AnimAction.Draw` 已经完成该筛选）。
